# Sustainable Development Goals Tableau Dashboard

This Tableau project analyses Sustainable Development Goal (SDG) data using interactive visualisations, trend analysis, regional comparisons, and forecasting.

## Project Overview
The project explores progress across selected SDGs and compares performance between countries and regions over time. It was developed as part of coursework in Data Science and Machine Learning.

## Features
- SDG index score trends over time
- SDG 13: Climate Action analysis
- SDG 8: Decent Work and Economic Growth analysis
- SDG 4: Quality Education analysis
- Regional performance comparisons
- 10-year forecast visualisation
- Interactive dashboard design in Tableau

## Tools Used
- Tableau
- CSV datasets
- Data visualisation
- Forecasting
- Dashboard design

## Key Insights
- Denmark and Sweden consistently showed strong SDG performance.
- China demonstrated clear long-term improvement across multiple indicators.
- Lower-performing countries and regions faced challenges linked to conflict, weaker infrastructure, and limited resources.
- OECD regions performed strongly in overall SDG progress compared to several developing regions.
